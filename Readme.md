# FastSD CPU (pip version)

The *fastsdcpu-pip* module is designed to provide fast inference of **Stable Diffusion** (based on LCM) on **CPUs** and **AI PCs** (Accelerated Inference). It is optimised for non-GPU hardware architectures, notably through the use of OpenVINO** (for Intel optimisation) and **GGUF**-type models (via the PyTorch/LCM pipeline).
